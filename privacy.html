drive-multi-mcp（個人用）

プライバシーポリシー

このポリシーは、運用者本人がGoogle DriveをAIアシスタントから利用するために構成した、個人用の連携に適用します。

取得する情報と権限

接続先アカウントを識別するためのメールアドレスなどの基本情報、Googleが発行する認証情報、および利用者の依頼に必要なDriveのファイル情報・内容を扱います。

現在の設定では、Google Driveの読み取り専用権限と、アカウント識別用の権限を要求します。読み取り専用権限の範囲は、接続したアカウントがアクセスできるDriveファイル全体です。

利用目的

アカウントの接続と識別、ファイルの検索・読み取り、利用者が依頼した内容の確認・要約などに利用します。広告、販売、信用評価のためにGoogleのユーザーデータを利用しません。

保存と送信

接続用の認証情報は利用者のPCに保存し、Google APIへのアクセスと認証の更新に使います。ローカルのMCPはGoogle APIを呼び出してファイル情報・内容を取得します。

利用者がAIアシスタントに検索・読み取りを依頼した場合、必要なファイル情報・本文は利用中のAIサービスに渡されます。そのサービスでの処理・保存・学習への利用などは、当該サービスの規約、プライバシーポリシー、および利用者のアカウント設定に従います。

Googleから取得したデータは、利用者が依頼した機能を提供する目的に限定して扱います。Google API Services User Data PolicyのLimited Use要件を遵守します。

保護と削除

認証ファイルを公開リポジトリに含めたり、他の利用者に共有したりしない運用とします。利用者はGoogleアカウントの接続管理からアクセス許可を取り消し、PC上の認証情報を削除することで連携を終了できます。AIサービス上のチャットや保存データは、そのサービスの管理機能から別途削除できます。

問い合わせ

個人用の構成については、Googleの認証画面に表示されるユーザーサポートメールにお問い合わせください。一般向けのサポート窓口は提供していません。
